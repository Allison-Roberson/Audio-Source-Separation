# Audio-Source-Separation
"Source_Separation.py" contains code, initially written by ZahraBenslimane, to separate an audio source into separate audio clips. Some parts of the code were added/changed to account for multiple sources, rather than multiple notes. It uses Nonnegative Matrix Factorization (NMF) on the spectrogram matrix of the audio source. Input your audio clip and the number of sources, and this code outputs the waveform of the clip and the spectrogram. It then applies NMF on the spectrogram matrix using a cost function (beta divergence). It outputs some iterations of the spectrograms for the new audio sources, showing W (the matrix containing the frequency activations) and H (the matrix containing the time activations). It reconstructs the separate audio sources into their own waveforms, and outputs a new audio file of each. 
"source_separation_W_H_matrices.py" follows similar code to above, but will print off the W and H data matrices. 
"Spectrogram_Matrix.py" plots the waveform, the spectrogram, the spectrogram matrix, finds the  nonnegative rank of that matrix, and outputs the corresponding W and H matrices according to that nonnegative rank.
